# 実装タスク: title-suggestion-agent

## Task Format

- [ ] 1. スキル基盤のセットアップ
- [x] 1.1 スキルディレクトリと SKILL.md の骨格を作成する
  - `.claude/skills/title-suggestion-agent/` ディレクトリを作成する
  - SKILL.md のフロントマター（name・description・トリガーキーワード）を記述する
  - スキルの役割定義（タイトル提案エージェントとしての動作目的）と動作フェーズの全体概要を定義する
  - 起動宣言「タイトル候補の生成を開始します」の出力ルールを記述する
  - _Requirements: 1.1_

- [x] 1.2 (P) ArticleContext スキーマ拡張を article-agent 設計ドキュメントに反映する
  - `.kiro/specs/article-agent/design.md` の Logical Data Model に `title?: string` フィールドを追記する
  - title フィールドの意味（title-suggestion-agent が確定操作後に設定するオプション値）をコメントで補足する
  - 既存スキル（article-writer・article-reviewer・article-thumbnail）の SKILL.md に「title フィールドが設定されている場合はそれを最終タイトルとして参照する」旨の注釈を加える
  - _Requirements: 5.2_

- [ ] 2. コンテンツ入力・解析フェーズの実装
- [x] 2.1 入力バリデーションと不足情報の案内ルールを SKILL.md に記述する
  - 入力テキストが 100 文字未満の場合に処理を停止して補完を求めるメッセージを返すルールを定義する
  - ArticleContext も記事本文も提供されていない場合の案内メッセージ（前工程スキルへの誘導）を定義する
  - バリデーション通過後にのみ解析フェーズへ進むフロー制御ルールを記述する
  - _Requirements: 1.3_

- [ ] 2.2 コンテンツ解析と制約適用のルールを SKILL.md に記述する
  - 記事本文テキストからトピック・主要キーワード・文体を抽出する解析ルールを定義する
  - ArticleContext が渡された場合に theme・targetAudience・purpose・style を優先参照するルールを定義する
  - ターゲット読者・媒体・トーンが追加指定された場合に候補生成へ反映する優先度ルールを記述する
  - _Requirements: 1.1, 1.2, 1.4_

- [ ] 3. タイトル候補生成フェーズの実装
- [ ] 3.1 5アプローチタイプ別の候補生成ルールを SKILL.md に記述する
  - 問いかけ型・断言型・ノウハウ型・数字型・キャッチコピー型の各アプローチ定義と生成ガイドラインを記述する
  - 最低5件の候補を異なるアプローチで生成するルールを定義する
  - 各候補にアプローチ種別と選定理由（1〜2文）を必ず付記するルールを定義する
  - タイトルが 40 文字を超える場合に短縮候補を自動付記するルールを記述する
  - 言語設定（デフォルト: 日本語）に基づいて候補を生成するルールを明記する
  - _Requirements: 2.1, 2.2, 2.4, 5.3_

- [ ] 3.2 スタイル指定対応の追加候補生成ルールを SKILL.md に記述する
  - ユーザーが「SEO重視」「キャッチコピー風」などのスタイルを指定した場合に検出するルールを定義する
  - スタイル指定検出時に3件以上のスタイル特化候補を追加生成するルールを記述する
  - 追加候補も通常候補と同じアプローチ種別・理由・スコアリングの対象とするルールを明記する
  - _Requirements: 2.3_

- [ ] 4. スコアリングフェーズの実装
- [ ] 4.1 3軸スコアリングのルールを SKILL.md に記述する
  - クリック誘引度・明瞭さ・コンテンツ整合性の各軸の評価基準（1〜5 段階）を定義する
  - 各スコアに根拠を添えることを参考指標であり最終判断はユーザーに委ねる旨とともに SKILL.md に明記する
  - 60 秒以内のレスポンス制約を意識したスコアリング処理の軽量設計方針を記述する
  - _Requirements: 3.1, 5.4_

- [ ] 4.2 スコア集計・ソート・品質警告ルールを SKILL.md に記述する
  - 3軸スコアの合計（3〜15）を算出して総合スコアとして付記するルールを定義する
  - 総合スコア降順でタイトル候補を並べて提示するルールを定義する
  - すべての候補の総合スコアが 3 未満の場合に品質不足警告と追加生成提案を返すルールを記述する
  - _Requirements: 3.2, 3.3_

- [ ] 5. フィードバック反復フェーズの実装
- [ ] 5.1 TitleSuggestionSession ブロックの出力ルールを SKILL.md に記述する
  - ラウンド番号・各ラウンドの候補一覧・確定タイトルを含む `## TitleSuggestionSession` ブロックの書式を定義する
  - 候補生成・フィードバック反復・確定の各操作後に TitleSuggestionSession ブロックを会話に出力するルールを記述する
  - ユーザーが「ラウンドN の候補X を見せて」などの過去参照要求に応じられるようにセッション全体を保持するルールを明記する
  - _Requirements: 4.3_

- [ ] 5.2 フィードバック反映の派生候補生成ルールを SKILL.md に記述する
  - 「もっと短く」「疑問形にして」など自然言語フィードバックを検出して反映するルールを定義する
  - フィードバック対象候補と修正指示を組み合わせて3件以上の派生候補を生成するルールを定義する
  - 派生候補にも通常候補と同じスコアリング・ソート・品質警告を適用するルールを記述する
  - _Requirements: 4.1_

- [ ] 6. 確定・出力フェーズの実装
- [ ] 6.1 確定操作と ArticleContext 書き戻しルールを SKILL.md に記述する
  - 「これで決定」などの確定操作フレーズを検出して selectedTitle を確定するルールを定義する
  - ArticleContext が渡されている場合に title フィールドのみを更新して他フィールドを保持するルールを定義する
  - TitleSuggestionSession の selectedTitle に確定タイトルを設定して最終 Session ブロックを出力するルールを記述する
  - _Requirements: 4.2, 5.2_

- [ ] 6.2 最終出力フォーマットルールを SKILL.md に記述する
  - 確定タイトルの選定理由・スコアを含む Markdown サマリー出力フォーマットを定義する
  - 更新済み ArticleContext ブロック（title フィールド追加）の出力フォーマットと出力条件を定義する
  - ArticleContext が提供されていない場合は Markdown 出力のみを返すフォールバックルールを記述する
  - _Requirements: 5.1, 5.2_

- [ ] 7. 検証シナリオの作成

- [ ] 7.1 (P) シナリオ E のサンプル入出力ファイルを作成する
  - `examples/input/scenario-e.md` にフルパイプライン入力（article-facilitator の ArticleContext + タイトル提案指示）を作成する
  - `examples/output/scenario-e-titles.md` に5件以上の候補・スコア・TitleSuggestionSession ブロック・確定後の更新済み ArticleContext を含む参照出力を作成する
  - article-facilitator → title-suggestion-agent → article-writer への引き継ぎ動作（title フィールドの流れ）を検証できる内容にする
  - _Requirements: 1.4, 2.1, 2.2, 3.1, 3.2, 4.1, 4.2, 4.3, 5.1, 5.2_

- [ ] 7.2 (P) シナリオ F のサンプル入出力ファイルを作成する
  - `examples/input/scenario-f.md` に記事本文テキスト直接入力（ArticleContext なし）とフィードバック1回のシナリオを作成する
  - `examples/output/scenario-f-titles.md` に初回候補・フィードバック反映後の派生候補・確定 Markdown 出力（ArticleContext なし）を含む参照出力を作成する
  - 100 文字未満入力・スタイル指定の各バリデーションケースのサンプルも補足として含める
  - _Requirements: 1.3, 2.3, 4.1, 5.1, 5.3, 5.4_
