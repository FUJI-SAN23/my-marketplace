`.claude/skills/article-editor/SKILL.md` を作成する。

`.claude/skills/article-editor/checklist.md` を作成する。

- 挿入判定の基本方針（1セクション1件・50%以内ルール）

- 📊 図表・グラフの判定基準（強い/補助）
- ⚠️ 注意コールアウトの判定基準
- 💡 ポイント・補足コールアウトの判定基準
- 📌 その他（AI 判断）の判定基準
