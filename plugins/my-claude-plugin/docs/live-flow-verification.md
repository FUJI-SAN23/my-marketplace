# 実会話フロー検証 — 2026-10-25

## 結果

Claude Codeにローカルプラグインを読み込ませ、通常フロー8ターンと独立3ケース、計11応答を実行した。タイトル提案・短縮案・確定からwriter・reviewer・editor・thumbnailへの受け渡しは成功。検証範囲内にスキル修正を要する不具合は見つからず、実行用スキルは変更していない。

確定したタイトル: **初心者の家計記録入門｜記録して週末に振り返る**

## 実行環境と証拠

- Claude Code 2.1.300、実行モデル `claude-opus-5-5`（モデル指定なし、CLIの既定値）。
- `--plugin-dir` に統合先の my-claude-plugin を指定。インストールや公開はしていない。
- `--tools Read,Skill --allowedTools Read,Skill --permission-mode dontAsk`。外部MCPとフックを無効にし、プラグイン資料の読取りとスキル実行だけを許可した。
- 01〜08は同じセッションを `--resume` で継続し、実際の応答を読んで次のターンへ進めた。境界ケースは独立した新規セッション。
- 保存した [実応答データ](live-flow-2026-10-25/evidence.json) は入力・応答・実行時間・モデル・検証対象のSHA-256を含む。期待出力を実績として転記したものではない。
- 最初はOAuth認証期限切れで実行できなかった。ユーザーの再ログイン後に実行成功。成功した11応答すべてでAPIエラーとツール権限拒否はなし。
- CLIの会話ログで各プラグインの名前空間付きコマンド展開、および共通契約・writerテンプレートのReadを確認した。

## 再照合

リポジトリルートから以下を実行する。保存済み応答の機械照合であり、新しいモデル呼び出しは行わない。Python標準ライブラリだけを使用する。

```sh
python3 plugins/my-claude-plugin/scripts/verify_live_flow.py
```

実会話を再実行する場合はevidence.jsonのpromptを順番に送る。候補IDは新しい応答に合わせて選び直す。新規セッションでプラグインを読み込み、後続ターンは同じsession_idを指定して継続する。
