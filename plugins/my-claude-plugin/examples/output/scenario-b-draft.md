## Gitとは何か? バージョン管理を1分で理解する

Gitは「ファイルの変更履歴を保存しておくツール」です。

たとえばPythonでプログラムを書いているとき、「うまく動いていたバージョンに戻したい」と思ったことはありませんか？　Gitを使うと、過去のどの時点のコードにも戻ることができます。

Gitを使う主なメリットは3つです。

- **いつでも過去に戻れる** — 失敗しても大丈夫という安心感が生まれる
- **変更の記録が残る** — 「何を・なぜ変えたか」が後から確認できる
- **チーム開発に必須** — 複数人で同じコードを扱うときの衝突を防ぐ

今は1人で使う場合でも「いつでも過去に戻れる」というメリットだけで十分価値があります。

## Git のインストールと初期設定

まずGitをパソコンにインストールして、使える状態にしましょう。

### Windows・Mac 別インストール手順

**Windowsの場合**

1. [https://git-scm.com/download/win](https://git-scm.com/download/win) にアクセスする（確認要）
2. インストーラーをダウンロードして実行する
3. 設定はデフォルトのままで「Next」を押し続けてOK
4. インストール完了後、「Git Bash」というアプリが使える状態になる

**Macの場合**

1. ターミナルを開く（Spotlight検索で「ターミナル」を検索）
2. `git --version` と入力する
3. Gitがインストールされていない場合、自動的にXcode Command Line Toolsのインストール案内が表示される
4. 案内に従ってインストールを完了する

### ユーザー名とメールアドレスの設定

インストール後、最初に「誰がコミットしたか」を設定します。

```bash
git config --global user.name "あなたの名前"
git config --global user.email "あなたのメールアドレス"
```

設定は一度行えばOKです。後から変更もできます。

## 最初のリポジトリを作ってみよう

いよいよ実際にGitを使ってみましょう。「リポジトリ」とは、Gitが管理するフォルダのことです。

### git init でリポジトリを作成する

まず、管理したいプロジェクトのフォルダを作り、Gitリポジトリとして初期化します。

```bash
mkdir my-python-project
cd my-python-project
git init
```

`git init` を実行すると「Initialized empty Git repository...」というメッセージが表示されます。これで準備完了です。

### ファイルを追加して最初のコミットをする

試しに簡単なPythonファイルを作成して、最初のコミットをしてみましょう。

```bash
# Pythonファイルを作成（Macの場合）
echo 'print("Hello, Git!")' > hello.py

# Gitの状態を確認する
git status

# ファイルをステージングエリアに追加する
git add hello.py

# コミットする（変更を保存する）
git commit -m "最初のコミット: hello.pyを追加"
```

`git commit` が成功すると、最初の「セーブポイント」が作成されます。

## よく使う基本コマンド5選

Gitには多くのコマンドがありますが、最初に覚えるのは5つだけで十分です。

### status / add / commit / log / diff

| コマンド | 役割 | 使用例 |
|---------|------|--------|
| `git status` | 現在の状態を確認する | `git status` |
| `git add` | 変更をステージングに追加する | `git add ファイル名` または `git add .`（全ファイル） |
| `git commit` | ステージングの内容を保存する | `git commit -m "コメント"` |
| `git log` | コミット履歴を確認する | `git log` |
| `git diff` | 変更内容を確認する | `git diff` |

この5つのコマンドを組み合わせることで、日常的なGit操作の90%は対応できます（確認要）。

## まとめ

この記事で学んだことを整理します。

- **Gitはセーブポイントを作るツール** — 失敗してもいつでも過去に戻れる
- **インストールは5分で完了** — 設定はユーザー名とメールアドレスだけ
- **`git init` でリポジトリを作成** — フォルダをGitの管理下に置く
- **`git add` → `git commit` がコミットの基本** — ステージング→保存のセットを覚える
- **基本コマンドは5つだけ** — status / add / commit / log / diff

**今日できる最初のアクション**: 今学習中のPythonプロジェクトのフォルダで `git init` を実行してみてください。それだけで、あなたのコードがGitの管理下に入ります。
