# シナリオA 入力: ビジネスノウハウ記事（情報完全・最短フロー）

このファイルは article-facilitator に渡す入力シミュレーションです。
テーマ・読者・目的・体験談・文体指定がすべて揃っており、最短フローで ArticleContext まで到達できることを確認します。

---

## ユーザー入力（1ターン目）

```
副業でコンテンツ販売を始めたいと思っています。
記事のテーマは「会社員が副業でコンテンツ販売を始める方法」です。
読者は30代の会社員で、副業に興味があるが何から始めればいいかわからない人を想定しています。
目的は「記事を読み終えたあとに、最初のコンテンツ企画書を書いてみようと思ってもらうこと」です。
文体はです・ます調でお願いします。
```

---

## 期待する article-facilitator の動作

1. テーマ・読者・目的・文体をすべて抽出できる
2. 「以下の内容で理解しています」として確認メッセージを返す
3. 情報が揃っているため追加質問なしで構成案提示フェーズへ進む
4. H2・H3 見出し構成案を提示する
5. ユーザーが承認したら ArticleContext を出力する（フェーズゲート G1 通過）

---

## ユーザー入力（2ターン目: 体験談提供）

```
補足です。私は3年前に副業コンテンツ販売を始めました。
最初の3ヶ月は月収500円以下でしたが、ターゲット設定を変えたら4ヶ月目から月3万円を超えました。
今は月10万円ほどが副業収入になっています。
最初に失敗したのは「誰でも役立つ情報」を出そうとして、結局誰にも刺さらなかったことです。
```

---

## 期待する article-facilitator の動作（体験談受け取り後）

1. 体験談を一次情報として記録する
2. 「以下の体験談を一次情報として取り込みました」と確認する
3. 構成案に体験談を織り込んだ更新版を提示する（または初回提示に反映する）

---

## 期待する ArticleContext 出力

```markdown
## ArticleContext

- **テーマ**: 会社員が副業でコンテンツ販売を始める方法
- **想定読者**: 30代の会社員。副業に興味があるが何から始めればいいかわからない人
- **目的**: 記事を読み終えたあとに最初のコンテンツ企画書を書いてみようと思ってもらう
- **伝えたい要点**:
  - ターゲット設定が売上を決定する最重要因子
  - 「誰でも向け」は誰にも刺さらない（失敗パターン）
  - 最初の3ヶ月は収益より学習と割り切る重要性
- **一次情報・体験談**:
  - 副業開始から3年の実体験
  - 最初の3ヶ月は月収500円以下
  - ターゲット変更後4ヶ月目から月3万円超
  - 現在は月10万円の副業収入
  - 失敗原因: 「誰でも役立つ情報」を出して誰にも刺さらなかった
- **文体**: です・ます調
- **構成案**:
  - ## なぜコンテンツ販売は最初に稼げないのか
    - ### 「誰でも向け」が最大の罠
    - ### 最初の3ヶ月に期待すること
  - ## 売れるコンテンツを作る「ターゲット設定」の考え方
    - ### ターゲットを絞るほど刺さる理由
    - ### ターゲット設定の具体的な手順
  - ## 会社員が副業コンテンツ販売を始める5ステップ
    - ### Step1: 自分の専門領域を棚卸しする
    - ### Step2: ターゲットを1人のペルソナに絞る
    - ### Step3: 最初のコンテンツ企画書を書く
    - ### Step4: 最小限のコンテンツを作って出す
    - ### Step5: フィードバックを受けて改善する
  - ## まとめ: 今日から始めるコンテンツ販売
- **確認日時**: 2026-03-04T10:00:00+09:00
```
