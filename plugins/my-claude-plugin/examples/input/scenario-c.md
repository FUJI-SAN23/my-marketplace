# シナリオC 入力: 体験談ベース記事（一次情報・一般論の区別検証）

このファイルは article-writer の一次情報取り扱い機能を検証するためのシミュレーションです。
体験談・メモが豊富に提供され、article-writer の出力で `【一次情報】` タグと一般論の区別が
明確に行われることを確認します。

---

## ユーザー入力（1ターン目）

```
転職活動について記事を書きたいです。
読者は30代で今の会社に不満があるけど転職を踏み出せない会社員です。
目的は「この記事を読んで転職活動を始めようと思ってもらうこと」です。
```

---

## ユーザー入力（2ターン目: 体験談とメモの提供）

```
私自身の体験談を共有します。

【私の転職経歴】
・新卒から8年間、同じメーカーに勤務
・35歳のときに「このまま定年まで勤める」と思うと焦りを感じ転職活動開始
・在職中に活動し、4ヶ月で内定を3社から獲得
・現在の年収は転職前の1.3倍（550万 → 715万）

【転職活動で学んだこと】
・最初の1ヶ月は応募書類の準備に費やした（職務経歴書を7回書き直した）
・エージェント2社を並行して使ったが、使い分けが大事だと気づいた
・面接で聞かれた質問のうち80%が「転職理由」「なぜうちの会社か」「5年後のビジョン」の3つに集中
・内定を断るのが一番精神的に辛かった

【後悔したこと】
・もっと早く動けばよかった（30歳くらいで始めていれば選択肢が広かった）
・最初から年収交渉をしなかった（1社目で年収交渉せず、後から後悔）

文体は断定調でお願いします。
```

---

## 期待する article-facilitator の動作

1. テーマ・読者・目的を抽出する（1ターン目で完了）
2. 体験談を一次情報として記録する（2ターン目）
3. 文体「断定調」を全体基準として設定する
4. 体験談を反映した構成案を提示する
5. ArticleContext に体験談をすべて記録して出力する

---

  - 後悔するなら早く動いたほうがいい
  - 年収交渉は最初からすべき
- **一次情報・体験談**:
  - 新卒から8年間同一メーカー勤務、35歳で転職活動開始
  - 在職中に活動し4ヶ月で内定3社獲得

- **構成案**:

    - ### 5年後のビジョン: キャリアの文脈で語る
  - ## やっておけばよかったこと（後悔と学び）
    - ### 30代前半から動いていれば
    - ### 年収交渉は最初からすべき
  - ## まとめ: 転職活動を始める最初の一歩
- **確認日時**: 2026-03-04T11:00:00+09:00

## 検証チェックリスト

- [ ] article-writer の出力で体験談に `【一次情報】` タグが付いている
- [ ] 一般的な転職アドバイスは `【一次情報】` タグなしで記述されている
- [ ] 断定調（「〜だ」「〜である」）が全体に統一されている
- [ ] 一次情報と一般論が混在せず明確に区別されている
- [ ] 一次情報の数値（年収・期間・割合）が正確に使用されている
