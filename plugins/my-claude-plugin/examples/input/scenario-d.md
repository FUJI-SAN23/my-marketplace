## 前提: 会話履歴に存在するコンテキスト

### ArticleContext（article-facilitator が出力済み）

```markdown
## ArticleContext

- **テーマ**: 会社員が副業でコンテンツ販売を始める方法
- **想定読者**: 30代の会社員。副業に興味があるが何から始めればいいかわからない人
- **目的**: 記事を読み終えたあとに最初のコンテンツ企画書を書いてみようと思ってもらう
- **伝えたい要点**:
  1. ターゲット設定が売上を決定する最重要因子
  2. 「誰でも向け」は誰にも刺さらない（失敗パターン）
  3. 最初の3ヶ月は収益より学習と割り切る重要性
- **一次情報・体験談**:
  - 副業開始から3年の実体験
  - 最初の3ヶ月は月収500円以下
  - ターゲット変更後4ヶ月目から月3万円超
  - 現在は月10万円の副業収入
  - 失敗原因: 「誰でも役立つ情報」を出して誰にも刺さらなかった
- **文体**: です・ます調
- **用途**: ノウハウ解説記事（ノウハウ図書館想定）
- **確認済み構成案**:
  ## なぜコンテンツ販売は最初に稼げないのか
  ### 「誰でも向け」が最大の罠
  ### 最初の3ヶ月に期待すること
  ## 売れるコンテンツを作る「ターゲット設定」の考え方
  ### ターゲットを絞るほど刺さる理由
  ### ターゲット設定の具体的な手順
  ## 会社員が副業コンテンツ販売を始める5ステップ
  ## まとめ: 今日から始めるコンテンツ販売
- **確認日時**: 2026-03-04T10:00:00+09:00
```

## 期待する article-thumbnail の動作

### ステップ 1: フェーズゲートチェック通過

- ArticleContext が存在することを確認する
- ArticleDraft が存在することを確認する（タイトル案参照モードで動作）

### ステップ 2: 起動宣言

```
サムネイル画像生成プロンプトの生成を開始します。

参照コンテキスト：
- ArticleContext: 存在する
- ArticleDraft:   存在する（タイトル案を参照します）
```

### ステップ 3: 3パターンのプロンプト生成

テーマ「副業コンテンツ販売」、読者「30代会社員」に適合した以下のようなコンセプトが期待される：

- パターン 1: ビジネス成功イメージ（グラフ・上昇ライン）
- パターン 2: 体験談・リアリティ重視（人物・ストーリー感）
- パターン 3: ステップ・ハウツー感（ロードマップ・数字）

各パターンに以下が含まれることを確認する：
- コンセプト名
- 選択理由（テーマ・読者との適合性）
- Nanobanana 向け英語プロンプト（自然言語叙述文）
- 4要素メモ（ビジュアルイメージ・テキストレイアウト・カラートーン・構図余白）

### ステップ 4: テキスト候補提案

ArticleDraft のタイトル案3本を参照して、サムネイル掲載テキスト候補を提案することを確認する。

## 検証チェックリスト（Task 7.1 + 7.2 共通）

### フェーズゲート（要件 6.1, 6.2）

- [ ] ArticleContext も ArticleDraft もない状態で起動した場合、前工程案内が返り処理が停止する
- [ ] ArticleContext が存在する場合はフェーズゲートを通過して処理が継続する

### プロンプト品質（要件 6.3, 6.4, 6.5, 6.6）

- [ ] 最低3パターンのプロンプトが生成される
- [ ] 各パターンにコンセプト名と選択理由が付与されている
- [ ] 各パターンにビジュアルイメージ・テキストレイアウト・カラートーン・構図余白の4要素が含まれる
- [ ] ArticleContext のテーマ・読者・目的が各パターンのコンセプトに反映されている

### Nanobanana 形式（要件 6.7）

- [ ] プロンプトがタグ羅列でなく自然言語叙述文で記述されている
- [ ] テキストレイアウトに表示テキスト内容・フォント・配置位置が具体的に記述されている

### テキスト候補（要件 6.8）

- [ ] ArticleDraft が存在する場合にタイトル案を参照したテキスト候補が提案される
- [ ] ArticleDraft が存在しない場合はテキスト候補をスキップし、その旨を案内する

### read-only 制約（要件 6.7）

- [ ] ArticleContext の内容が変更されていない
- [ ] ArticleDraft の内容が変更されていない
