# シナリオB 入力: 技術解説記事（情報不足・情報収集ループ検証）

このファイルは article-facilitator の情報収集ループを検証するためのシミュレーションです。
テーマのみ提供され、読者と目的が未提供の状態から始まります。
追加質問が2つ以内に収まり、情報収集ループが正しく機能することを確認します。

---

## ユーザー入力（1ターン目: テーマのみ）

```
Gitの使い方について記事を書きたいです。
```

---

## 期待する article-facilitator の動作（1ターン目）

1. テーマ「Gitの使い方」を抽出する
2. 読者・目的が未提供であることを検出する
3. 優先度順（テーマ → 読者 → 目的）に従い、**読者と目的**について最大2つの質問を行う
4. 1ターンで3つ以上の質問をしない（ルール: 最大2問）

**期待する質問の例（2問以内）:**
```
「Gitの使い方」について理解しました。

より良い記事を作るために、以下を確認させてください。

1. 読者はどんな方を想定していますか？（例: プログラミング初心者、チーム開発を始めたばかりのエンジニアなど）
2. この記事を読み終えたあと、読者にどんな状態になってほしいですか？（例: 基本コマンドを使えるようになる、チームでGitを使えるようになるなど）
```

---

## ユーザー入力（2ターン目: 追加情報提供）

```
読者はプログラミングを学び始めて半年くらいの初心者です。
独学でPythonを学んでいるけど、Gitを使ったことがない人を想定しています。
記事を読んだあとに、最初のGitリポジトリを自分で作れるようになってほしいです。
```

---

## 期待する article-facilitator の動作（2ターン目）

1. 読者（プログラミング初心者・Python学習中・Git未経験）を抽出する
2. 目的（最初のGitリポジトリを自分で作れるようになる）を抽出する
3. テーマ・読者・目的が揃ったことを確認する
4. 「以下の内容で理解しています」として収集情報のサマリーを提示する
5. 構成案提示フェーズへ進む（追加質問は行わない）

---

## ユーザー入力（3ターン目: 構成案承認）

```
その構成でお願いします。
```

---

## 期待する ArticleContext 出力

```markdown
## ArticleContext

- **テーマ**: Git入門: プログラミング初心者が最初のリポジトリを作るまで
- **想定読者**: プログラミング学習歴半年程度の初心者。Pythonを独学中でGitを使ったことがない人
- **目的**: 記事を読み終えたあとに最初のGitリポジトリを自分で作れる状態になる
- **伝えたい要点**:
  - Gitが「何のためのツールか」を直感的に理解する
  - インストールから最初のコミットまでをハンズオン形式で体験する
  - 失敗しても怖くない（操作を取り消せる）という安心感を持つ
- **一次情報・体験談**: なし
- **文体**: です・ます調（指定なし → デフォルト適用）
- **構成案**:
  - ## Gitとは何か? バージョン管理を1分で理解する
  - ## Git のインストールと初期設定
    - ### Windows・Mac 別インストール手順
    - ### ユーザー名とメールアドレスの設定
  - ## 最初のリポジトリを作ってみよう
    - ### git init でリポジトリを作成する
    - ### ファイルを追加して最初のコミットをする
  - ## よく使う基本コマンド5選
    - ### status / add / commit / log / diff
  - ## まとめ: 今日からGitを使い始めよう
- **確認日時**: 2026-03-04T10:30:00+09:00
```
